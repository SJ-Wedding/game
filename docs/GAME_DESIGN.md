# 균열 아레나 — 게임 기획서 (MVP)

## 1. 한 줄 소개
균열이 열린 원형 경기장에서 15분 동안 몰려오는 괴물을 쓰러뜨리며 강해지고, 13:30에 나타나는 **잿불 군주**를 15:00 전에 처치하는 탑다운 액션 로그라이크.

## 2. 목표와 원칙
- **바로 시작**: 타이틀에서 '플레이'(또는 Enter) 한 번이면 즉시 조작. 공격은 자동이라 이동과 회피에 집중한다. 튜토리얼 화면 없이 HUD 안내 문구로 조작을 알려 준다.
- **한 판 15분**: 표준 플레이의 승리는 전투 시간 14~15분에 끝난다. 시간은 실제 전투 중에만 흐른다.
- **선택이 체감되는 성장**: 레벨업마다 강화 3개 중 1개. 공격 속도·투사체 수·최대 체력·회피 대기시간처럼 즉시 손에 느껴지는 변화만 둔다.
- **공정한 위험**: 돌진·원거리·보스의 위험한 공격은 모두 방향이나 범위를 **미리 보여 준다**. 회피(Space)에는 짧은 무적이 있어 읽고 피하는 플레이가 보상받는다.
- **다시 하기 쉬움**: 결과 화면에서 Enter/Space/R 또는 버튼 한 번으로 새 판.

## 3. 핵심 루프
```
이동·조준·공격 → 적 처치 → 경험치 보석 흡수 → 레벨업(강화 3택 1) → 더 강한 적·엘리트 → 보스 → 결과 → 재시작
```

## 4. 조작
| 입력 | 동작 | 비고 |
| --- | --- | --- |
| WASD | 이동 | 대각선은 정규화(같은 속도) |
| (자동) | 조준·공격 | 사거리 540px 안에서 가장 가까운 적(보스 포함)을 매 순간 자동 조준해 초당 2.4회(기본) 발사. 대상에 청록 꺾쇠 표시, 플레이어 앞 흰 삼각형이 조준 방향. 사거리 안에 적이 없으면 공격하지 않음 |
| Space | 회피 | 0.2초 대시 + 0.32초 무적, 재사용 2.4초. 이동 키 방향(없으면 조준 방향) |
| Esc | 일시정지 | 탭이 숨겨지면 자동 일시정지 |

## 5. 콘텐츠

### 5.1 플레이어 — '균열 감시자'
청록색 원형 몸체 + 흰 테두리. 체력 100, 이동 220px/s, 투사체 피해 12.

### 5.2 일반 적 3종
| 이름 | 유형 | 모양·색 | 행동 | 읽을 거리(예고) |
| --- | --- | --- | --- | --- |
| 그림자 망령 | 추격형 | 보라색 원 | 플레이어를 곧장 쫓아와 몸으로 부딪힘 | — (느리고 약함, 숫자로 압박) |
| 뿔 돌격수 | 돌진형 | 주황 삼각형 | 360px 안에 들어오면 멈춰 0.8초간 **돌진 경로(붉은 띠)**를 표시한 뒤 직선 돌진 | 붉은 띠가 끝까지 차오르면 돌진 |
| 가시 포자 | 원거리형 | 노란 마름모 | 300~430px 거리를 유지하며 맴돌고, 0.5초간 **부풀며 중심이 분홍으로 빛난 뒤** 독침 발사 | 부풀어 오름, 느린 분홍 탄 |

### 5.3 엘리트 1종 — 균열 수호자
빨간 육각형 + 금색 테두리 + 머리 위 체력 바. 체력 700(시간 보정 별도). **돌진(붉은 띠 예고)** 과 **원형 파편 14발(붉은 원 확장 예고)** 을 번갈아 사용. 7:30, 10:00, 12:00에 등장하며 처치 시 큰 경험치 보석(30).

### 5.4 보스 — 잿불 군주
크림슨색 톱니 원형, 금색 테두리, 하단 전용 체력 바. 체력 9000. 13:30 등장(1.6초 등장 연출 동안 무적·자동 조준 제외).
| 패턴 | 예고 | 내용 |
| --- | --- | --- |
| 불씨 고리 | 보스 주위 붉은 원이 0.9초간 커짐 | 원형 탄막 20발 (2페이즈: 26발 × 2연발, 엇갈림) |
| 돌진 | 보스 폭의 붉은 띠 1.0초 | 820px/s 로 약 530px 직선 돌진 |
| 낙화 | 붉은 원 장판이 1.2초간 안쪽부터 차오름 | 플레이어 위치 + 주변에 장판 4개(2페이즈 6개) 폭발 |
| 소환 (2페이즈) | — | 그림자 망령 4마리 |
- 체력 50% 이하 → **2페이즈(격노)**: 1.2초 무적 연출, 공격 간격 1.5 → 1.1초, 소환 추가.
- 처치하면 **즉시 승리**.

### 5.5 강화 9종 (공격·생존·기동 각 3)
| 분류 | 이름 | 효과(중첩당) | 최대 중첩 |
| --- | --- | --- | --- |
| 공격 | 연사 숙련 | 공격 속도 +18% | 5 |
| 공격 | 분열 사격 | 투사체 +1 (부채꼴) | 3 |
| 공격 | 날 선 탄환 | 피해 +22% | 5 |
| 생존 | 강인한 육체 | 최대 체력 +25, 즉시 25 회복 | 4 |
| 생존 | 재생 | 초당 체력 0.8 회복 | 3 |
| 생존 | 수호 결계 | 받는 피해 -12% (곱연산) | 3 |
| 기동 | 질풍 걸음 | 이동 속도 +10% | 4 |
| 기동 | 순간 회피 | 회피 재사용 대기시간 -18% (곱연산) | 3 |
| 기동 | 흡수 영역 | 경험치 흡수 범위 +45% | 3 |

- 후보 3개는 중첩 한도에 도달하지 않은 강화 중에서 중복 없이 무작위로 뽑는다.
- 모두 최대면 '응급 처치(체력 30 회복)'가 대신 나온다.
- 선택 결과는 즉시 체감된다: 투사체 수·연사 속도·체력 바 길이·회피 게이지 회복 속도·흡수 범위 원(플레이어 주변 옅은 초록 원).

## 6. 15분 한 판 설계

| 구간 | 전투 시간 | 등장 | 생성 간격 / 동시 상한 | 의도 |
| --- | --- | --- | --- | --- |
| 적응 | 0:00–3:00 | 그림자 망령 | 1.5→1.0초 / 28 | 이동·공격 익히기. **첫 레벨업 약 40초** |
| 돌진형 등장 | 3:00–5:00 | + 뿔 돌격수 | 1.0→0.85초 / 36 | 예고선 읽기 학습 (안내 문구) |
| 원거리형 등장 | 5:00–7:00 | + 가시 포자 | 0.85→0.75초 / 42 | 거리 조절·탄 피하기 학습 |
| 혼합 | 7:00–11:00 | 3종 혼합, **엘리트 7:30·10:00** | 0.75→0.6초 / 52 | 빌드 차이가 드러나는 구간 |
| 고밀도 | 11:00–13:30 | 3종 혼합, 엘리트 12:00 | 2마리씩 0.95→0.8초 / 64 | 밀도는 높이되 상한으로 이동·회피 공간 확보 |
| 보스전 | 13:30–15:00 | **잿불 군주** + 망령 소량 | 3초 / 10 | 보스 집중. 처치 시 승리, 15:00 시간 초과 시 패배 |

- 적 체력은 분당 +10%, 피해는 분당 +3% 증가(등장 시점 기준).
- 경험치 곡선: 다음 레벨 필요량 = 22 + 4.6 × (레벨-1)^1.3 → 13:30 무렵 Lv 18 전후(강화 17개 내외).

### 시간 규칙
- 시간은 60틱/초 고정 틱으로만 흐른다. **강화 선택, 일시정지, 탭 숨김(자동 일시정지), 결과 화면**에서는 틱이 돌지 않아 전투 시간·스폰이 함께 멈춘다.
- 렉이나 탭 복귀로 프레임 간격이 커져도 한 프레임에 최대 0.1초만 진행한다(시간 순간이동 방지).

## 7. 화면 구성

| 화면 | 내용 |
| --- | --- |
| 타이틀 | 게임 이름, 한 줄 목표, **플레이(Enter)**, 조작 표, 최고 기록(최장 생존·최다 처치·최단 승리·승리/플레이), 음량. 개발 모드면 시드·시작 구간·무적 패널 |
| HUD | 좌상단: 체력 바, 경험치 바(Lv·수치), 회피 게이지(준비/남은 초). 중앙 상단: **남은 시간**(15:00부터 감소)과 '보스까지 m:ss'. 우상단: 처치 수. 하단: 보스 체력 바(보스 등장 후). 좌하단: 보유 강화 칩. 중앙: 안내 문구 |
| 레벨업 | 카드 3장(분류 색·이름·효과·현재/최대 중첩), 클릭 또는 1·2·3 |
| 일시정지 | 계속하기(Esc), 음량, 처음부터 다시, 타이틀로. 탭 숨김으로 멈춘 경우 안내 |
| 결과 | 승리/패배, **승패 원인**(보스 처치 / "○○의 △△에 쓰러졌습니다" / 시간 초과 + 보스 남은 체력), 생존 시간, 처치 수, 도달 레벨, 선택한 강화, 신기록 배지, 시드. 다시 시작(Enter·Space·R) |

## 8. 가독성 규칙 (색과 모양)
- 플레이어 계열은 **차가운 청록·흰색**, 적은 **보라·주황·노랑·빨강**의 서로 다른 **모양**(원·삼각형·마름모·육각형·톱니).
- 적 투사체는 **진분홍 + 흰 중심 + 바깥 글로우**로 가장 위에 그려 어떤 배경·적 위에서도 보인다. 플레이어 투사체는 작은 흰 탄 + 청록 꼬리.
- 공격 예고는 모두 **반투명 빨강 영역 + 밝은 빨강 테두리**로 통일하고, 진행도(띠가 차오름·원이 커짐·장판이 안쪽부터 채워짐)를 보여 준다.
- 경험치는 초록 마름모(엘리트 보석은 연두색 큰 마름모).
- 바닥은 어두운 남색 격자 + 옅은 균열 문양으로, 전경 요소보다 채도·명도를 낮춘다.

## 9. 저장
음량과 최고 기록만 저장(`localStorage`, 버전 1). 진행 중인 판은 저장하지 않는다(로그라이크).

## 10. MVP 범위 밖 (다음 단계 후보)
캐릭터 추가, 메타 성장, 맵 추가, 무기 종류, 배경 음악, 모바일 조작, 접근성 옵션(색약 팔레트·화면 흔들림 끄기), 난이도 선택.
